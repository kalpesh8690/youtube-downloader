Privacy

Last updated: 7 November 2026

Downly is designed as a self-hosted media inspection and download interface. In the Termux setup, requests are processed by the Node API and worker running on your own Android device.

Information processed

When you inspect a link, Downly sends the submitted URL to the configured worker to retrieve public page metadata and available media formats. When you start a download, the selected source URL and format are sent to the worker so it can stream the source or process it with yt-dlp and FFmpeg.

Native streaming downloads are not buffered into a complete file in the browser and are not intentionally saved as a completed file on the worker. Temporary operating-system or media-tool buffers may still be used during processing.

Local history

Downly stores a small download-history list in this browser's local storage. It includes display information such as title, thumbnail URL, filename, format and a sanitized source URL. Query strings and fragments are removed from the saved source URL to avoid retaining signed query tokens. This history remains in the browser until the browser's site data is cleared.

Logs and infrastructure

The worker's application logs omit URL query strings. The local Termux API and any tunnel, hosting provider or network infrastructure used to expose the app may still process connection metadata. Do not assume that a public tunnel is private merely because the worker itself listens on loopback.

Self-hosting security

Do not expose the Termux API or worker as an unrestricted public service. Use a named, access-protected tunnel such as Cloudflare Access, keep worker credentials private, and rotate any sample or previously shared token. Downly does not currently provide user accounts, per-user authentication or multi-tenant quotas.

Third-party websites

Media metadata, thumbnails and download streams may come from third-party websites. Those sites may receive requests from your device or worker and process them under their own privacy policies and terms.

Contact and changes

This page describes the current self-hosted implementation. Review the repository before exposing a modified deployment to other users.
